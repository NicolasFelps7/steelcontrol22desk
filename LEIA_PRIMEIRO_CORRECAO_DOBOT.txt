APLICAR NO WINDOWS
A) PARE o Edge e o DobotStudio e garanta que o braco nao esta em movimento.
B) Faca backup de toda a pasta do projeto (ou commit no Git).
C) Abra a pasta que contem backend, frontend e steelcontrol-edge.
D) Extraia ESTE ZIP nessa pasta, mantendo a estrutura de pastas.
   Quando perguntado, aceite substituir os 8 arquivos acima.
E) O Edge roda no PC local: reinicie INICIAR_STEELCONTROL_EDGE.bat
   quando o hardware estiver pronto.
F) O backend hospedado no Railway precisa receber a alteracao via Git:
   abra PowerShell na pasta do projeto e rode:
      git add backend/src/lib/dobotPolicy.js backend/test/dobot-security.test.js
      git add steelcontrol-edge/adapters/dobot_adapter.py steelcontrol-edge/edge_runtime.py steelcontrol-edge/tests/test_motion_telemetry.py steelcontrol-edge/tests/test_dobot_alarm_recovery.py
      git add frontend/assets/js/dobot-control-component.js frontend/operacao.html
      git commit -m "Corrige controle manual Dobot e diagnostico Edge"
      git push
   Se a branch principal tiver outra configuracao, siga o fluxo normal do seu repo.
G) No navegador, recarregue com Ctrl+Shift+R.
