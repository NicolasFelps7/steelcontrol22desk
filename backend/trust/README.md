# Arquivos públicos de confiança e revogação

Prepare `icp-brasil-raizes.pem` e `icp-brasil-lcrs.pem` a partir das fontes oficiais
para a cadeia do e-CNPJ utilizado. Confira as impressões digitais das raízes.
Inclua LCRs vigentes de todos os emissores e mantenha-as atualizadas.

Não coloque PFX, P12, chave privada ou senha de cliente nesta pasta.
Não use a PKI sintética dos testes como raiz de produção.

Veja `../../AUTORIZACAO_ECNPJ.md`. Sem configuração válida, o backend recusa a ativação.
